Before you begin

What this setup does

This replaces an unofficial WhatsApp connection with Meta's official WhatsApp Business Platform, also called the Cloud API. It is the right route for reliable business messaging.

Keep control of your accountYou do not need to be technical. Complete only the items labelled Aman to do. Never share your Facebook password, one-time verification code, API token or recovery code with anyone.

Keep these ready

1. Your own Facebook accountIt should belong to Aman and have two-factor authentication enabled.
2. Legal business informationBusiness name, address, email, website/social profile and phone number, matching official documents.
3. A supporting documentMeta may request a GST, registration, tax, utility or bank document. Use exactly what Meta asks for.
4. A working phone numberA number that can receive an SMS or phone call during setup.
5. A business emailAn email Aman checks himself and can use for Meta verification.
6. Billing accessA payment method may be needed for Meta's messaging charges.

Choose the number carefully

For the smoothest setup, use a new Aman Khurana business number that is not currently being used in personal WhatsApp, WhatsApp Business or the old WAHA setup.

Stop before migrating an existing numberIf Aman wants to use his existing coaching number, do not remove or transfer it yet. Send Vyzma a screenshot first so we can confirm the safe Meta route.
The full route

Eight simple stages

Business portfolio→Verification→Meta app→Phone number→Secure access→Templates→Testing

Step 1 — Create the Meta Business Portfolio

Aman to doOpen business.facebook.com on a computer and sign in with your own Facebook account.
  1. Choose Create business portfolio if one does not already exist.
  2. Enter the business name as Aman Khurana, or the exact registered business name.
  3. Enter your real name and a business email you check regularly.
  4. Open Business settings and confirm Aman is an admin with full control.
  5. Enable two-factor authentication if Meta asks.
Then send VyzmaA screenshot showing the Business Portfolio name and Aman as an admin. Hide any personal email address if you prefer.

Step 2 — Add correct business details

  1. In Business settings, find Security Center, Business info or Business verification. Meta sometimes changes these labels.
  2. Enter the legal business name, address, website, phone and email exactly as they appear on the supporting document.
  3. Start Business verification if the button is available. Upload only the document Meta requests.
  4. Complete any email, SMS or phone confirmation directly on Meta.
Good to knowMeta makes the approval decision. If verification is rejected, do not repeatedly change details. Send Vyzma the rejection screenshot so we can identify what does not match.
Create the official connection

Meta app and phone number

Step 3 — Create the official WhatsApp app

Aman to doOpen developers.facebook.com/apps using the same Facebook account.
  1. Select Create App.
  2. Choose the option for a Business app. If Meta asks for a use case first, choose the closest option to Other or Business.
  3. Name it Aman Khurana WhatsApp.
  4. Select the Aman Khurana Business Portfolio created earlier.
  5. After creation, find Add products and add WhatsApp.
  6. Open WhatsApp API Setup or Getting Started. The test number and temporary token shown there are only for testing.
Then send VyzmaA screenshot of the WhatsApp API Setup page. Do not include the access token in the screenshot.

Step 4 — Add the real business number

  1. Select Add phone number on the WhatsApp API Setup page.
  2. Enter the Aman Khurana business number and its country code.
  3. Enter business profile information truthfully.
  4. Use Aman Khurana as the display name clients will see.
  5. Choose SMS or phone-call verification and type the code only into Meta.
  6. Wait for Meta to confirm the number and review the display name.
Never share the codeVyzma will never ask for the SMS or call-verification code. It belongs only on Meta's verification screen.
Keep ownership with Aman

Safe access and messaging rules

Step 5 — Invite Vyzma securely

  1. Go to Business settings.
  2. Open Users or People, then choose Invite people.
  3. Invite the Vyzma email address supplied by Teja.
  4. Give only the permissions Vyzma confirms are needed. Aman remains the owner and full admin.
  5. Do not share your Facebook password, two-factor code or recovery codes.
What Vyzma does after access is granted
  • Create a secure long-lived server token.
  • Store secrets in protected app settings, never in chats or browser code.
  • Set up and secure the webhook for replies and delivery status.
  • Create approved message templates and test everything before launch.

Step 6 — Consent, templates and pricing

Meta charges for some business-initiated WhatsApp messages. Prices depend on destination, category and Meta's current policy. Review the current rate in Meta Business Manager before sending campaigns.

Before sending proactive reminders, record that each client agreed to receive WhatsApp messages from Aman Khurana. A suitable consent line is:

“I agree to receive coaching updates, appointment reminders and payment reminders from Aman Khurana on WhatsApp. I can opt out by replying STOP.”

Free-form replies are allowed only during Meta's 24-hour customer-service window after a client messages you. Outside that window, Aman must use a Meta-approved message template. Vyzma will submit the reminder templates before activating automation.

Go live only after proof

Final test and hand-off

Step 7 — Test in this order

  • Aman receives one test message on his own phone.
  • A test client receives one approved template message.
  • The client replies and the response reaches the coaching system.
  • A test check-in creates a coach alert.
  • A payment-status test does not create duplicate messages.
  • Aman confirms the display name, phone number and wording are correct.
Only thenWe switch on client automation after every test above passes.
